# FM-1 KEYS

Physical models for the M-VAVE FM-1: a tine electric piano with a modelled pickup, an exciter-and-resonator voice
(pluck, strike, bow, blow) on strings, tubes and bodies from wood to glass, metal and skin, and one-finger chords in
any key, voice-led, with strum.

**Test build 0.1-dev: emulator only, not yet on hardware.**

- Play it in the browser: https://soundbydrp-art.github.io/fm1-keys/
- Hear the 15 patches: https://soundbydrp-art.github.io/fm1-keys/audio/fm1-keys-tour.mp3
- Manual: [app/docs/MANUAL.md](app/docs/MANUAL.md) · Handoff notes: [app/HANDOFF.md](app/HANDOFF.md)
