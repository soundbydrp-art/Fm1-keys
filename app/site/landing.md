# FM-1 KEYS

Physical models for the M-VAVE FM-1: a tine electric piano with a modelled pickup, and an exciter-and-resonator voice
(pluck, strike, bow, blow) on strings, tubes and bodies of wood, glass, metal and skin. One-finger chords in any key,
voice-led, with strum.

This is version {{VERSION}}. You install it at your own risk, and the installer can put M-VAVE's own firmware back.

- [Try it in the browser](emu/). It runs the same code as the FM-1, with sound.
- The [Manual](manual/) explains the screen, the controls and the patches.
